SCOPECAST synchronises one scoped agent policy from Base Sepolia to Unichain Sepolia through Reactive Omni.
A source event is validated on Lasna and mirrored into an authenticated callback.
Four steps, each independently verifiable by transaction receipt.
Nine capability fields are bound by one canonical hash.
Dual callback authentication, monotonic epochs and a fail closed guard.
The console reads real chain state and refuses to guess.
A test wallet is connected here for the interface only. No signing key is stored by the app.
Real receipts show the source transaction, the Reactive transaction and the destination callback.
The agent policy is at epoch two and revoked on the destination.
Agent key, target, selector, cap, expiry and hash are all visible.
Before revocation, the guarded vault executed a bounded two unit test action.
After revocation, the same action is rejected. The denial is shown as a labelled eth call simulation.
The audit trail links every event to the correct chain explorer.
Diagnostics verify chain IDs, addresses, system contract, callback proxy and gas reserve.
Trust boundaries and strictly newer epoch invariants are documented.
